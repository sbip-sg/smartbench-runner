# Smartbench Runner

# Installation

- Install Python virtual environment:

  ```sh
  cd smartbench-runner
  ./install/setup-venv.sh
  ```

# Usage

   ```sh
   ./smartbench.sh -f examples/Rubixi.sol -t slither --debug
   ```

# Development

- Code formatting is performed by `black` (see configuration in `pyproject.toml`).
